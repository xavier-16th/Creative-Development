# 🌌 The Emotions - Site Web Interactif

Un site web créatif et immersif explorant les émotions humaines à travers l'univers Star Wars. Ce projet combine des animations visuelles captivantes avec une narration poétique pour créer une expérience unique.

## 📖 Description

**The Emotions** est une expérience web interactive qui présente les émotions comme des personnages de l'univers Star Wars :

- **🩷 Master Love** - Un sage Jedi symbolisant l'amour, la compassion et l'empathie
- **🔥 Padawan Desire** - Un apprenti passionné représentant le désir et la quête de connexion
- **⚡ Darth Anger** - Un Seigneur Sith incarnant la colère et la rage

## ✨ Fonctionnalités

- **Champ d'étoiles animé** - Des étoiles flottantes créent une atmosphère spatiale immersive
- **Effets d'éclairs** - Des éclairs rouges générés dynamiquement sur canvas pour la section "Colère"
- **Animations au scroll** - Les sections s'animent lors du défilement grâce à l'Intersection Observer API
- **Style Star Wars** - Un défilement de texte inspiré de l'intro emblématique des films
- **Design responsive** - S'adapte à toutes les tailles d'écran
- **Effet Glitch** - Animation glitch sur le titre principal

## 🛠️ Technologies Utilisées

- **HTML5** - Structure sémantique
- **CSS3** - Animations, transitions et effets visuels avancés
- **JavaScript (ES6+)** - Logique d'animation et interactivité
- **Canvas API** - Génération d'éclairs dynamiques
- **Vite** - Outil de build rapide pour le développement
- **Google Fonts** - Police Audiowide pour le style futuriste

## 🎨 Sections du Site

1. **Landing Page** - Page d'accueil avec titre animé et navigation
2. **Introduction Star Wars** - Texte défilant style "crawl"
3. **Master Love** - Section rose avec cœurs animés
4. **Padawan Desire** - Section avec effets de feu
5. **Darth Anger** - Section sombre avec éclairs sur canvas


## 💡 Inspiration

Ce projet explore la dualité des émotions humaines en les présentant comme une bataille entre le côté lumineux et obscur de la Force. L'objectif est de montrer que même les émotions les plus intenses peuvent être comprises et canalisées.
